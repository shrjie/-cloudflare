# 福山國中傳染病通報單線上系統 — Google Sites 版部署說明

本站版把「前端網頁＋後端程式」放在同一個 Google Apps Script 專案，
部署一次即可，不需要 Netlify，也不需要在 HTML 裡設定網址。

## 檔案說明
- `site/Code.gs`：後端＋網頁提供（doGet 送出前端、google.script.run 處理存取）。
- `site/index.html`：前端網頁（家長填報／老師管理），貼到 Apps Script 的 HTML 檔案。
- 上層舊檔（`Code.gs`、`index.html`、`README.md`）是 Netlify 版，保持不動。

## 部署步驟

### 1. 建立後端（Google 試算表 + Apps Script）
1. 開一份新的 Google 試算表（例如命名「福山國中傳染病通報單_資料庫」）。
2. 上方選單「擴充功能」→「Apps Script」。
3. 把 `site/Code.gs` 的內容整段貼上，取代預設的 `Code.gs` 內容。
4. 在 Apps Script 左側檔案列表旁按「+」→「HTML」，檔案名稱取為 `index`，
   把 `site/index.html` 的內容整段貼上，取代預設內容。
   > 注意：HTML 檔名必須是 `index`，後端 doGet 會讀取這個檔案。
5. 管理密碼：**不需再設定指令碼屬性**。第一次使用預設為 `admin123`，
   登入後請到「系統管理」立即修改。密碼以加鹽 SHA-256 雜湊存放在
   試算表 `Settings` 工作表（`PWD_HASH`／`PWD_SALT`），不存明文。
   若舊專案曾設定 `TEACHER_PASSWORD`，首次執行會自動遷移並刪除該屬性。
6. 右上角「部署」→「新增部署作業」：
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
7. 授權完成後，複製產生的網址（結尾為 `/exec`），在瀏覽器打開確認能看到填報首頁。

### 2. 放上 Google Sites
1. 進入你的 Google Sites 編輯頁面，新增或選擇要放置的頁面。
2. 右側「插入」→「嵌入」→「依網址」，貼上上一步的 `/exec` 網址 →「插入」。
3. 把嵌入區塊拉高（表單很長，建議直接設為整頁高度；至少 1600px 以上才好填寫）。
4. 右上角「發佈」即上線。
> 列印小提醒：老師按「匯出列印」時若瀏覽器印出整個 Sites 頁面，可直接在新分頁開啟 `/exec` 網址操作再列印，版面即為單張 A4 通報單。

### 3. 之後更新
- 改好 `site/` 檔案後，到 Apps Script「部署」→「管理部署作業」→ 編輯 → 版本選「新版本」→「部署」，Sites 上的內容會同步更新。

## 使用方式
- **家長填報**：輸入身分證字號 → 顯示名下全部通報（新→舊），每筆標示通報時間、診斷摘要與狀態。
  - 「＋新增通報」隨時可建新案（舊案鎖定不影響新案）。
  - 每筆通報後 **24 小時內可編修**（顯示剩餘時間）；逾期自動鎖為唯讀，後端也以 `_rowId`＋期限驗證拒絕覆寫（回傳 expired）。
  - 第 12 欄（簽名與通報時間）家長端不顯示，由老師填寫；家長編修時後端自動保留老師已填內容。
- **日期時間輸入**：民國日期欄改用 date picker 點選（自動換算顯示「民國 X 年 X 月 X 日」，存入既有 `_y/_m/_d`，舊資料相容）；月日欄改用下拉選單點選；時間欄為 time picker 點選。
- **老師管理**：以密碼登入 → 可搜尋、查看、編修、刪除所有通報紀錄（含第 12 欄簽名與通報時間）→ 點「匯出列印」會開啟瀏覽器列印視窗，版面對照原始紙本通報單欄位排版（A4 直式一頁），選擇「另存為 PDF」即可輸出成 PDF 存檔或列印。**管理不受 24 小時限制**。
- **系統管理**（老師登入後下方卡片）：可修改學校名稱＋網頁標題（前台頂欄、瀏覽器分頁標題、doGet 標題同步更新）；可修改管理密碼（需舊密碼，新密碼至少 8 碼含英數、不可用 admin123）。

## 密碼安全性說明
- 存放：只存 `salt + SHA-256(salt::password)`，試算表 `Settings` 內無明文；`getAdminSettings` 絕不回傳雜湊，只回傳是否為預設密碼與更新時間。
- 傳輸：經 `google.script.run`（HTTPS POST），密碼不進 URL；前端密碼欄已改為 `type=password`。
- 驗證：後端比對雜湊；登入成功發 2 小時 token，所有管理 API 皆驗 token。
- 防暴力破解：連續 5 次失敗鎖定 10 分鐘（CacheService），前端顯示剩餘次數。
- 政策：新密碼 ≥8 碼、需含英文字母＋數字、不可等於 `admin123`、不可與舊密碼相同；仍為預設密碼時登入後會顯示紅色警告。
- 權限：試算表僅擁有者／受託管理員可開，家長端拿不到 Settings；請勿將試算表共用給全校，並定期備份。

## 安全性提醒
- 家長端以身分證字號作為查詢索引，並未另外設密碼，僅適合校內小範圍、家長彼此無法得知其他學生身分證字號的情境；如需更高安全性，可自行加上驗證碼或簡訊驗證機制。
- 老師密碼登入後會取得 2 小時效期的存取權杖，逾時需重新登入。
- 系統儲存的是學生／教職員工的健康與個資，請留意校內資安規範，並定期備份試算表。
