# 福山國中傳染病通報單線上系統 — 部署說明

## 檔案說明
- `index.html`：前端網頁（家長填報／老師管理），可直接部署到 Netlify 或任何靜態網站空間。
- `Code.gs`：後端程式碼，貼到 Google Apps Script，資料儲存在 Google 試算表。

## 部署步驟

### 1. 建立後端（Google 試算表 + Apps Script）
1. 開一份新的 Google 試算表（例如命名「福山國中傳染病通報單_資料庫」）。
2. 上方選單「擴充功能」→「Apps Script」。
3. 把 `Code.gs` 的內容整段貼上，取代預設的 `Code.gs` 內容。
4. 在 Apps Script 編輯器左側「專案設定」（齒輪圖示）→「指令碼屬性」→ 新增：
   - 屬性名稱：`TEACHER_PASSWORD`
   - 值：（自訂老師登入密碼，例如 `Fushan2026!`）
   > 若未設定，系統預設密碼為 `admin123`，**請務必設定成自己的密碼再啟用**。
5. 右上角「部署」→「新增部署作業」：
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**
6. 授權完成後，複製產生的網址（結尾為 `/exec`）。

### 2. 設定前端
1. 打開 `index.html`，找到最上方：
   ```js
   const GAS_URL = "PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE";
   ```
2. 換成剛剛複製的網址（保留引號）。
3. 存檔。

### 3. 上線
- **最簡單**：直接把 `index.html` 拖曳到 [Netlify Drop](https://app.netlify.com/drop) 即可取得公開網址。
- 或放到學校既有的網頁空間、GitHub Pages 等任何可放靜態 HTML 的地方。
- 之後若要修改表單內容或密碼，改好 `Code.gs` 或 `index.html` 後，重新「管理部署作業」更新版本即可（Apps Script 需選「新版本」才會套用最新程式碼）。

## 使用方式
- **家長填報**：輸入孩子身分證字號 → 若已有紀錄會帶出上次填寫內容供編修；若沒有則開新表單。每個身分證字號只保留「最近一筆」通報紀錄，重新送出會覆蓋前一筆。
- **老師管理**：以密碼登入 → 可搜尋、查看、編修、刪除所有通報紀錄 → 點「匯出列印」會開啟瀏覽器列印視窗，版面對照原始紙本通報單欄位排版，選擇「另存為 PDF」即可輸出成 PDF 存檔或列印。

## 安全性提醒
- 家長端以身分證字號作為查詢索引，並未另外設密碼，僅適合校內小範圍、家長彼此無法得知其他學生身分證字號的情境；如需更高安全性，可自行加上驗證碼或簡訊驗證機制。
- 老師密碼登入後會取得 2 小時效期的存取權杖，逾時需重新登入。
- 系統儲存的是學生／教職員工的健康與個資，請留意校內資安規範，並定期備份試算表。

## 可自行調整的地方
- 表單各區塊的選項（診斷項目、症狀等）定義在 `index.html` 的 `DIAGNOSIS_OPTIONS` / `SYMPTOM_OPTIONS` / `FAMILY_DISEASE_OPTIONS` 陣列中，可直接增刪。
- 版面色彩（粉色／藍色）定義在 `<style>` 區塊最上方的 CSS 變數（`--rose-*`、`--sky-*`），可依需求微調。
